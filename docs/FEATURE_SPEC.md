# HA'WE — 기능 명세서 (간단 버전)

`docs/BACKEND_DB.md`(백엔드 설계)와 `frontend/myApp/www/`(화면 목업) 기준으로 정리한 최소 기능 명세.

## 한 줄 요약
그룹마다 매일 미션이 하나씩 열리고, 내가 먼저 제출해야 그룹원들 게시물을 볼 수 있는 그룹 인증 앱.

## 화면 ↔ 기능 매핑

| 화면 | 파일 | 기능 |
|---|---|---|
| 로그인 | `index.html` | 카카오/Apple 소셜 로그인 |
| 그룹 목록 | `pages/main.html` | 내 그룹 목록, 그룹별 오늘 제출 여부(미제출/제출 완료) 뱃지, 새 그룹 만들기/초대받기 진입, 알림 아이콘 |
| 오늘의 미션(잠김) | `pages/mission-locked.html` | 오늘의 미션 텍스트 표시, 내가 미제출이면 그룹원 게시물은 블러 처리로 숨김("먼저 제출해야 볼 수 있어") |
| 미션 제출 | `pages/mission-submit.html` | 사진 첨부 + 캡션 작성 후 제출 |
| 그룹 피드 | `pages/group-feed.html` | 오늘의 미션 + 그룹원 제출물 목록(제출한 사람만), 스티커 반응 개수·댓글 수 미리보기, 미제출 멤버에게 콕찌르기/똥뿌리기 |
| 게시물 상세 | `pages/post-detail.html` | 게시물 원본 보기, 스티커 반응 남기기, 댓글 작성(`@멘션`, 사진 첨부) |
| 마이페이지 | `pages/mypage.html` | 이번 달 달력에 날짜별 도장(참잘했어요/벌점) 표시, 날짜 목록으로도 확인 |
| 하루 상세 | `pages/day-detail.html` | 특정 날짜의 미션·내 제출물·도장 결과, 그룹 피드로 이동 |
| 멤버 목록 | `pages/members.html` | 그룹 멤버별 이번 달 제출 횟수·오늘 도장, 미제출 멤버 콕찌르기, 그룹 설정 진입 |
| 그룹 설정 | `pages/group-settings.html` | 그룹명 변경, 미션 발행 시간 변경, 멤버 초대(링크), 알림 설정, 그룹 나가기 |
| 알림함 | `pages/notifications.html` | 콕찌르기/댓글/멘션/미션 도착 등 알림 목록 |
| 캐릭터 선택 | `pages/characters.html` | 프로필로 쓸 캐릭터 선택 |

## 핵심 비즈니스 규칙
- **잠금 규칙**: 오늘 내가 제출하지 않으면 그룹 피드(그룹원 게시물)를 볼 수 없다.
- **도장 규칙**: 별도 상태 저장 없이, 해당 날짜에 내 제출 기록이 있으면 "참잘했어요", 없으면 "벌점".
- **재촉 기능**: 미제출 멤버에게 `콕찌르기` 또는 `똥뿌리기`를 보낼 수 있고, 상대에게 알림이 간다.
- **미션 발행**: 그룹마다 설정한 시각에 그날의 미션이 자동으로 열린다.

## MVP 범위
- 포함: 소셜 로그인, 그룹 CRUD/멤버 관리, 미션 발행/조회, 제출, 잠금 피드, 댓글(+멘션), 스티커 반응, 콕찌르기/똥뿌리기, 알림, 마이페이지 달력, 캐릭터 선택.
- 제외(추후 확장): Qdrant 기반 회고 추천 기능(`RecallService`).
