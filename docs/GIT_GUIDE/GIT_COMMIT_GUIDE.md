Git 커밋 메시지는 아래 형식으로 작성합니다.

`type(scope): 작업 내용`

예시  
`feat(auth): 로그인 기능 추가`  
`fix(user): 회원 조회 오류 수정`

각 type 의미
- `feat` : 새로운 기능 추가
- `fix` : 버그 수정
- `docs` : 문서 수정
- `refactor` : 코드 구조 개선/리팩토링
- `test` : 테스트 코드 추가·수정
- `chore` : 설정, 패키지, 빌드 등 기타 작업

`scope`는 선택사항이며 수정한 영역을 적습니다.  
예: `auth`, `user`, `payment`

작업 내용은 짧고 명확하게 작성하면 됩니다.
