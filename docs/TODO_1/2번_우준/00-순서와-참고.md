## 다른 사람과 주고받는 지점

- **B10 은 둘이 나눠서 한다.** 우준이 비전 서비스를 먼저 만들어 `curl -F image=@x.jpg -F topic=창밖 풍경` 으로 동작을 확인하고 알리면, 찬희가 Spring 연동(Key Points 7~15)을 한다. 둘 사이 약속은 `POST /v1/topic-fit` 하나뿐이다. 임계값은 우준의 평가(`EVAL.md`) 결과로 정해 찬희에게 넘긴다.
- **`SubmissionService` 를 고치는 순서**: B0(우준) → B1(찬희) → B5(우준) → B10 연동(찬희) → B4(찬희). B5 는 찬희의 B1 이 push 된 뒤 시작한다.
- 찬희의 Android 가 기다리는 것: A2 ← 우준 A1(완료), A9 ← 우준 A8(+ B11). 경환(iOS)이 기다리는 것: iOS 항목 6·8·9·7 ← 우준의 A4·A7·A8·A6, iOS 항목 9 ← M1 결과물(`ml/quickdraw/export/`, `golden/`, `PREPROCESS_SPEC.md`).
- 우준의 Android 가 기다리는 것: A7 ← A4(같은 화면) + 찬희 B10 연동(실제 확인용), A8 ← A7(+ M1), A6 ← 찬희 A9(+ B7). **A4 와 찬희의 A3 는 같은 파일을 고친다** — 먼저 끝난 쪽이 바로 푸시·알리고 다른 쪽은 pull 후 이어 간다. 끝나면 바로 알려 준다.
- iOS 는 경환이 옮기고 테스트한다. 우준이 끝낸 A0·A1·A4·A7·A8·A6 도 마찬가지다(원하면 우준이 Windows 에서 iOS 초안을 쓰고 경환이 빌드·수정 — 10단계 iOS 선례).

## 겹치는 파일 주의

- **B7** 은 `GroupService`/`GroupSummaryResponse`/`GroupMemberMapper`/`PokeService` 도 고친다(찬희 영역). 시작 전에 찬희와 말하고, 시작 직전 pull·끝나자마자 push.
- **B9** 는 V1(`missions` 컬럼)과 `SecurityConfig`(`/internal/**`)를 고친다. 찬희에게 알리고, 모두 로컬 DB 재생성.
- **Android** 계획끼리 `DataStore.kt`, `MainNavigation.kt`, `MissionScreen.kt`, `ResultsScreen.kt`, `HIcon.kt` 가 계속 겹친다 → 아래 "Android 순서"를 지키고, 하나 끝날 때마다 바로 커밋·푸시·알림.
- B0 와 찬희의 B1 은 동시에 진행해도 겹침이 적다(B0: `SubmissionService`/`SubmissionResponse`, B1: `SubmissionMapper`/`SubmissionRow`). 먼저 끝난 쪽이 바로 push.
- B8 의 임시 기본 프롬프트·서버 안내는 `src/main/resources/mission-ai/`(깃에 올림)에 두었다. 우준 PC 에만 있는 팀원 프롬프트(`src/main/resources/prompts/`)는 `.gitignore` 라 섞이지 않는다.

## 진행 방법 (3명 공통)

1. 시작 전에 `git pull`. 앞 단계 담당자의 커밋이 들어왔는지 확인.
2. 계획 파일 내용을 `.agent/plan.md` 에 복사해 AI(Codex/Claude)에게 맡기거나, Claude Code 에서 계획 파일을 직접 읽혀 진행.
3. 보고서·리뷰 후 **바로 커밋·푸시**하고 단톡에 "B○ 끝" 알림. 커밋 메시지는 팀 형식 `type(scope): 내용` (예: `refactor(mission): 음성 기능 제거`).
4. V1 을 고쳤으면 단톡에 알리고, 다른 사람은 pull 후 로컬 DB 를 비우고 다시 만든다.
5. 테스트: 백엔드 `.\mvnw.cmd clean test -q`, Android 는 JDK 21 로 `android\gradlew.bat :app:testDebugUnitTest`(계획 파일의 JDK 경로는 이 PC 에 맞게), Python 은 각 `ml/*` 폴더의 `pytest`. Python 은 TensorFlow 호환을 위해 **3.12** 로 가상환경을 만든다(`py -3.12 -m venv .venv`). 이 PC 는 디스크 여유가 약 40GB 라 Quick, Draw! 데이터는 범주별 앞부분만 받는다.
