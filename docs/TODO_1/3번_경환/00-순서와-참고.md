# 3번 경환 — iOS 이식 · iOS 테스트

작성: 2026-10-12, 갱신: 2026-10-15. 3명 분담(1번 찬희 · 2번 우준 · 3번 경환)의 3번 안내서다. 공통 규칙과 전체 일정은 `1번_찬희/00-순서와-참고.md` 맨 아래에도 같이 있다.

## 맡은 영역

`ios/`(A5) 전부와 iOS 테스트(팀에서 아이폰이 경환뿐).
**Android 는 더 맡지 않는다.** A2·A3·A9 는 2026-10-15 찬희에게 옮겼다(`1번_찬희/`). 우준의 A0·A1·A4·A6·A7·A8 과 합쳐 Android 구현은 찬희·우준이 하고, 경환은 **구현된 Android 를 iOS 로 옮기는 일만** 한다.
서버·Android 쪽 계약은 찬희·우준의 B·A 계획이 정한다. iOS 는 그 계약을 그대로 따른다.

## 할 일: iOS 이식 (`A5-ios-port.md`) — Mac 필요

A5 는 Android 결과를 iOS 로 옮기는 **묶음 계획**이다. 항목 0~10 을 Android 해당 단계가 끝날 때마다 하나씩 옮긴다.

| A5 항목 | 옮길 Android 결과 | 담당(Android) | 시작 조건 |
|---|---|---|---|
| 0 | A0 음성 제거 | 우준 | 완료 — 지금 가능 |
| 1 | 10단계 달력·활동 요약 | (이미 코드 있음) | **Mac 빌드 확인만 남음** (우준 커밋 `6b0ad46`. A5 문서에는 "보류"로 적혀 있지만 빌드 확인만 하면 된다) |

- 이식할 Android 가 생기면 만든 사람(찬희 또는 우준)이 단톡에 알린다. 원하면 Windows 에서 iOS 초안을 써 줄 수 있고(10단계 iOS 선례), 경환은 빌드·수정·테스트만 한다.
- Windows 에서는 컴파일이 안 된다. Mac 에서 `xcodegen generate` 후 빌드·실행 확인. Mac 이 없으면 팀에서 Mac 있는 사람과 조율.
- 새 틀 6종(A4)은 Android·iOS 둘 다 배포되기 전에는 서버에서 켜면 안 된다(구 앱이 새 틀을 못 그림). iOS 항목 6 이 끝나면 우준에게 알린다.
- A2 참고: 우준 PC 의 로컬 브랜치 `backup/step8-kang` 에 프로필 편집·사진·탈퇴 앱 연결 초안(Android·iOS)이 있다(그룹 내 프로필 부분은 B1 계약과 다르니 쓰지 않는다).
- 기다리는 동안: 항목 0·1·2·3 처럼 이미 끝난 Android 부터 옮기고, Figma 가 나오면 임시 이미지(`*_temp`, `stamp_*`) 교체.

## 겹치는 파일 주의

- Android 와는 디렉터리가 달라 충돌하지 않는다. 다만 **문서**(`docs/FRONTEND/*`, `PROJECT_OVERVIEW.md`)는 다른 사람도 고치니 pull 후 작업.

## 직접 해야 하는 일

- Mac·아이폰(실기기/시뮬레이터)에서 동작 확인.
- 우준의 M1 평가용으로 **그림 그려 주기**(범주 라벨과 함께) — iOS 앱으로도 가능.
- iOS 앱 라이선스 화면에 Quick, Draw!(CC BY 4.0) 출처 표기 — A5 항목 9 완료 조건.

## 진행 방법

1. 시작 전에 `git pull`. 옮길 Android 커밋이 들어왔는지 확인.
2. 계획 파일 내용을 `.agent/plan.md` 에 복사해 AI(Codex/Claude)에게 맡기거나, Claude Code 에서 계획 파일을 직접 읽혀 진행.
3. 보고서·리뷰 후 **바로 커밋·푸시**하고 단톡에 "A5 항목 ○ 끝" 알림. 커밋 메시지는 팀 형식 `type(scope): 내용` (예: `feat(ios): 콕 찌르기 연결`).
4. 서버 쪽 V1 이 바뀌었다는 알림을 받으면 로컬 DB 를 비우고 다시 만든 뒤 서버를 켠다.
