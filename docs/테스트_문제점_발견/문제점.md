## 6. AWS 서버에 서버 수정 배포 (한수)

- **발견:** 2026-10-19, AWS 서버로 가입을 테스트하다가 발견
- **내용:** 아래 서버 수정이 GitHub에는 올라갔지만 AWS 서버에는 아직 반영되지 않았을 수 있어요. 반영 전까지 AWS에서는 예전처럼 동작해요.
  - 회원가입 이메일 중복 확인(`POST /api/auth/email-check`). 반영 전에는 앱이 확인을 건너뛰어요.
  - 사진 AI 호출 HTTP/1.1 고정(`VisionClient`). 사진 배지를 쓰려면 비전 프로그램(`ml/vision-service`)도 AWS에 설치하고 `HAWE_VISION_ENABLED=true`가 필요해요. 이제 ONNX 방식이라 PyTorch 없이 `requirements.txt`로 설치하고(약 230MB), `models/`에 ONNX 파일 3개(약 450MB)만 복사하면 돼요. 파일은 우준 노트북에 있어요(`ml/vision-service/README.md` "ONNX").
  - 미션 문장 조사 맞추기(`KoreanJosa`)
  - 30초 스케치 발행 중단(`hawe.mission.enabled-templates`, 기본 풀)
  - 삼행시 빈 줄 허용(`SubmissionService.validateAcrostic`). 반영 전에도 새 앱은 빈 줄을 빼고 보내서 올릴 수 있어요.
  - 제한 문구를 뺀 새 미션 프롬프트(`src/main/resources/prompts/`). 서버를 다시 시작해야 적용돼요.
- **할 일:** 최신 `main`으로 AWS 서버를 다시 배포하고, `POST /api/auth/email-check`가 응답하는지 확인해 주세요.

## 9. 시간 제한 없는 그리기 틀을 새로 둘지 (결정 필요)

- **발견:** 2026-10-19, 8번(30초 스케치 중단)을 적용하면서
- **내용:** 30초 스케치를 빼서 그리기 미션이 "A를 B로" 하나만 남았어요. 그리기 차례마다 "A를 B로"가 나오고, 하루 미션이 4개 이상인 그룹은 같은 날 "A를 B로"가 두 번 나올 수 있어요(문장은 AI가 다르게 써요).
- **정할 것:** 시간 제한 없이 주제만 주는 그리기 틀(예: "자유 그리기")을 새로 둘지. 두면 서버 틀 정의, 프롬프트, Android·iOS 화면(지금 그림판 그대로 쓸 수 있음)을 추가해야 해요.
