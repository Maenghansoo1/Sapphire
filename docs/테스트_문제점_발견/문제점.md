# 테스트 중 발견한 문제점

테스트하다 발견한 문제를 여기에 모아 두고, 고칠 때 한꺼번에 반영해요.

- 새 문제는 아래 형식으로 번호를 이어서 추가해 주세요.
- **고친 문제는 [문제점_해결.md](문제점_해결.md)에 기록하고 이 문서에서는 빼요.** 이 문서에는 아직 안 끝난 문제만 남겨요.
- 해결해서 뺀 문제: 1번(갤러리 미션 버튼), 2번("A를 B로" 그림 미션), 3번(찍는 미션에 예전 사진). 1·2번 원래 설명은 git 기록(커밋 `22a55c7`)에 있어요.
