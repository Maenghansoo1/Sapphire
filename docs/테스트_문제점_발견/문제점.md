# 테스트 중 발견한 문제점

테스트하다 발견한 문제를 여기에 모아 두고, 고칠 때 한꺼번에 반영해요. 새 문제는 아래 형식으로 번호를 이어서 추가해 주세요.

---

## 1. "갤러리 발굴" 미션인데 버튼이 "사진 찍기"라서 카메라로만 올리는 것처럼 보임

- **발견:** 2026-10-16, Android 테스트 (미션 "갤러리에서 가장 최근 웃은 사진을 골라줘")
- **증상:** 갤러리에 있는 사진을 올리라는 미션인데 미션 카드의 버튼이 "사진 찍기"예요. 사진을 새로 찍어야만 하는 것처럼 보여요.
- **결정:** 갤러리 미션은 **앨범에서 고르기와 사진 찍기 둘 다 되게** 해요.

### 원인

앨범에서 고르는 기능은 이미 있어요. 사진 수행 화면 왼쪽 아래의 작은 그림 아이콘이 "앨범에서 고르기" 버튼이에요(Android·iOS 둘 다). 문제는 화면이 이 미션을 다른 사진 미션과 똑같이 보여 준다는 점이에요.

1. **미션 카드 버튼 글자가 항상 "사진 찍기"예요.** 사진 미션이면 틀(template)에 상관없이 같은 글자가 나와요.
   - Android: `missionActionTitle` (`feature/mission/MissionFormat.kt:62`)
   - iOS: `actionTitle` (`Core/Models/TodayMission.swift:5`)
2. **사진 수행 화면은 미션 틀을 몰라요.** 주제 문장만 넘겨받아요. 그래서 갤러리 미션에서도 화면 대부분이 카메라 미리보기이고, 앨범 버튼은 글자 없는 작은 아이콘이라 눈에 잘 안 띄어요.
   - Android: `MissionPerformScreen.kt:31` → `PhotoMissionScreen`
   - iOS: `MissionPerformView.swift:28` → `PhotoMissionView`
3. **화면에 들어가자마자 카메라 권한부터 물어봐요.** 갤러리 미션에서도 마찬가지예요. 권한을 거부하면 "설정에서 카메라 권한을 켜 주세요"가 떠서, 앨범으로 올릴 수 있는데도 막힌 것처럼 보여요. 앨범 고르기에는 권한이 필요 없어요.
4. 앨범에서 사진을 고른 뒤에도 버튼이 "다시 찍기"로 나와요.

### 고칠 방향 (Android·iOS 둘 다)

- 미션 카드 버튼: `PHOTO_GALLERY`이면 "사진 고르기"처럼 고르는 동작이 드러나는 글자로 바꿔요. iOS는 미션 모델에 틀 값이 있는지 먼저 확인해 주세요.
- 사진 수행 화면에 틀 값을 넘겨요. `PHOTO_GALLERY`일 때는 이렇게 바꿔요.
  - "앨범에서 고르기"를 글자가 있는 큰 주 버튼으로 하고, 카메라는 보조로 둬요.
  - 화면에 들어가자마자 카메라 권한을 묻지 않아요. 카메라를 쓰려고 할 때 물어봐요.
  - "다시 찍기"를 "다시 고르기"로 바꿔요.
- 다른 사진 틀(`PHOTO_NOW` 지금 이 순간, `PHOTO_COLOR` 색깔 사냥)은 지금처럼 카메라 위주로 둬요.
  - **결정 필요:** 이 틀에도 앨범 버튼이 있어서 "지금 이 순간" 미션에 예전 사진을 올릴 수 있어요. 이대로 둘지 팀에서 정해 주세요.

### 서버

수정할 것은 없어요. `PHOTO_GALLERY`는 원래 갤러리에서 사진을 찾는 틀이에요(`MissionTemplate.java:7`, `docs/FEATURE/MISSIONS.md`의 "갤러리 발굴"). 이번 미션 문구는 AI를 연결하지 않았을 때 쓰는 예시 문구예요(`PlaceholderMissionGenerator.java:43`).

### 확인 방법

개발자 모드 → 개발자 도구 → 미션 생성에서 `PHOTO_GALLERY`를 고르면 같은 상황을 바로 만들 수 있어요.
